One broadsheet image summing up Wednesday 25 November 2026: 36 stories, all dated that day — 3 heroes, 11 illustrated cards, 22 briefs, a world map with numbered pins, and a DATE CHECK footer listing the other days' news that was left out.

## How it works

`main.py` is a self-contained, standard-library-only Python program. It draws the whole 1024×1024 page in code — masthead, numbers row, three vector-illustrated heroes, illustrated story cards, the world map (from `countries.geo.json`), briefs, and the DATE CHECK footer — and writes `entry.png`.

Run it:

```sh
python3 -P -s main.py
```

The image is written to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`). The output is deterministic: two runs produce byte-identical PNGs.

## Stories

All 36 stories happened, or were first reported, on Wednesday 25 November 2026, as reported by Reuters, AP, AFP, ABS, pm.gov.au, Yonhap, QNA, SCMP, Cybernews, SeatBeat, LiveLaw, and AJP. Every card carries its source and a CONFIRMED / OFFICIAL / REPORTED badge (see the HOW SURE legend on the page). Asia-Pacific leads the day with 15 of the 36 stories.
